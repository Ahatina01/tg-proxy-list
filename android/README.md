# TG Proxy

Минималистичное Android-приложение на Kotlin. Android 8.0 (API 26) и новее.

Нажмите «Подключить». Приложение скачает список, параллельно проверит MTProto-прокси и передаст исходную ссылку официальному Telegram. При необходимости подтвердите подключение в Telegram.

Источник: https://raw.githubusercontent.com/Ahatina01/tg-proxy-list/main/proxies.txt

## Поведение

- Новый HTTP-запрос при каждом нажатии, с запретом локального HTTP-кэширования.
- При ошибке загрузки или отсутствии распознаваемых MTProto-ссылок используется последняя корректная копия, затем встроенный снимок списка от 20 ноября 2026 года.
- Все параметры выбранной ссылки передаются без изменений.
- До восьми проверок одновременно; общий бюджет проверки 12 секунд; отдельный сокет закрывается через 4,5 секунды. Загрузка списка занимает отдельное время.
- Проверяются Fake TLS HMAC (секрет `ee`), обфусцированный MTProto и ответ `resPQ` с исходным nonce. Также поддержаны обычные 16-байтовые секреты и `dd`.
- Это проверка пути до Telegram, а не полная авторизация и не гарантия дальнейшей работы сети.
- Выбирается минимальная измеренная задержка среди успешно проверенных адресов. При повторной попытке ранее переданный прокси исключается, если есть проверенная альтернатива: приложение не может узнать, подтвердил ли пользователь подключение и работает ли затем Telegram.
- WEB Proxy намеренно пропускаются: корректная проверка и совместимость не реализованы.
- Открываются только пакеты `org.telegram.messenger` и `org.telegram.messenger.web` через ACTION_VIEW. Если они отсутствуют, показывается просьба установить официальный Telegram.
- Фонового переключения Telegram нет. Серверы и секреты на экран не выводятся.
- Единственное разрешение — INTERNET. Нет VPN, root, рекламы, аналитики, аккаунтов приложения или собственного backend.

## Сборка

Откройте эту папку в Android Studio. Нужны JDK 17, SDK Platform 35 и Build Tools 35.0.0; Gradle Wrapper 8.9 включён. Gradle скачает AGP 8.7.3 и Kotlin 2.0.21.

На Windows с JDK 17 рекомендуется распаковать проект и Gradle cache в путь без кириллицы, например `C:\dev\TG-Proxy`, чтобы избежать ошибки кодировки Java argument files при запуске тестов.

```powershell
./gradlew.bat testDebugUnitTest
./gradlew.bat assembleDebug
```

Для release задайте переменные окружения, не записывая пароль в репозиторий:

```powershell
$env:TG_KEYSTORE = 'путь-к-приватному/tgproxy.jks'
$env:TG_STORE_PASSWORD = 'пароль-из-вашей-приватной-копии'
./gradlew.bat assembleRelease
```

Alias ключа: `tgproxy`. Для обновления уже установленного APK нужны прежний ключ и увеличенный `versionCode`.

Ключ и пароль не включены в проект. Отдельный архив `TG-Proxy-signing-PRIVATE.zip` предназначен только владельцу: храните его отдельно и не публикуйте. Пользователям отправляйте только `TG-Proxy.apk`.

## Тесты

Unit-тесты покрывают разбор и сохранение ссылок, отбрасывание некорректных адресов, выбор, повторную попытку, кэш, резерв, неверный nonce и TCP-сервер без MTProto. `TG_LIVE_TEST=1` включает сетевую проверку GitHub и доступных прокси; без переменной этот тест не обращается к сети.

Транспорт реализован по документации https://core.telegram.org/mtproto/mtproto-transports и проверен на текущем списке. Проверка не выполняет вход в Telegram.
