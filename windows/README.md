# TG Proxy для Windows

**[Скачать TG-Proxy.exe](https://github.com/Ahatina01/tg-proxy-list/raw/refs/heads/main/downloads/TG-Proxy.exe)**

Один переносимый EXE для Windows 10/11 с .NET Framework 4.8. Установка и права администратора не нужны. На актуальных Windows 10/11 .NET Framework уже входит в систему; на старых сборках Windows может потребоваться установка 4.8.

## Использование

Запустите официальный Telegram Desktop хотя бы один раз, чтобы он зарегистрировал ссылки `tg://`. Запустите TG Proxy и нажмите «Подключить». После проверки прокси откроется окно Telegram — подтвердите подключение самостоятельно.

Windows открывает зарегистрированный обработчик `tg://`: если вы назначили сторонний клиент обработчиком этих ссылок, откроется он. TG Proxy не меняет системные ассоциации. Для портативного Telegram сначала нужно зарегистрировать протокол средствами клиента.

## Поведение

- При каждом нажатии загружается [proxies.txt](https://raw.githubusercontent.com/Ahatina01/tg-proxy-list/main/proxies.txt). Меняйте этот файл на GitHub; пересборка EXE не нужна.
- При сбое сети используются последняя корректная копия и встроенный резерв. Кэш и прошлый выбор находятся в `%LOCALAPPDATA%\TG Proxy`.
- До восьми проверок одновременно, бюджет проверки около 12 секунд, отдельное соединение — до 4,5 секунды. Загрузка списка имеет отдельный таймаут 6,5 секунды.
- Поддерживаются MTProto-секреты обычного типа, `dd` и Fake TLS `ee`. Проверяются HMAC и настоящий `req_pq_multi/resPQ` с совпадением nonce; открытого TCP-порта недостаточно.
- Выбирается минимальная измеренная задержка. При повторном нажатии выбирается другая проверенная доступная запись, если она есть.
- Для открытия меняется только префикс `https://t.me/proxy?` на `tg://proxy?`; строка параметров передаётся без изменений.
- WEB Proxy пропускаются. Нет автоматического переключения уже подключённого Telegram, VPN, root, рекламы, регистрации и собственного backend.
- Проверка не выполняет полную авторизацию Telegram и не гарантирует дальнейшую стабильность сервера.

## Сборка и тесты

Исходники: C# и WinForms, без сторонних библиотек. Компилятор C# находится в установленном .NET Framework.

```powershell
powershell -File .\build.ps1 -Test
powershell -File .\build.ps1 -Test -Live
```

Результат: `bin\TG-Proxy.exe`. Тесты: `bin\Tests.exe`. `-Live` обращается к GitHub и текущим прокси; обычные тесты используют только loopback.

EXE не имеет Authenticode-подписи: платный сертификат издателя не использовался. Поэтому Windows может показывать предупреждение о неизвестном издателе. APK-подпись Android к EXE неприменима.

См. [отчёт проверки](../docs/windows-verification.txt). Локальные исходники соответствуют опубликованной сборке 1.0.0.0.
